# ROM License Registry

All ROMs bundled in RetroBox are from the [retrobrews](https://github.com/retrobrews) project, which curates freely-distributable NES homebrew games.

> **Note:** The README of the source collection states: *"The ROMs listed here have been approved for free distribution on this site/project only. If you want to share it, please contact owner/developer."*

This means users can play these ROMs through RetroBox, but redistribution outside this project context should be verified individually with each developer.
